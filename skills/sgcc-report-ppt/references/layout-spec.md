## 2. 内容区网格（布局库 L1–L8）

内容区：x **39–1253**（宽 1214），y **232–666**（高 434）。外壳（标题区、导语条、页脚、主色、字号阶梯）每页相同，**不随布局变化**。

三条硬约束（任何布局都必须满足）：

1. 各栏宽度之和 + 16px 栏间距 = **1214**；
2. 栏间距统一 **16px**，不为某套布局单独调松或调紧；
3. 内容顶边 ≥ 232、底边 ≤ 666（`visual_qa.py` 有断言，容差 6px）。

> 布局只决定「内容区怎么切」，不引入任何新颜色、新字号、新圆角。所有卡片仍用第 3 节的通用样式。

### L1 左图卡 + 右栏（主力，参考第 4 页）

```
┌──────────────────────┬──────────────┐
│  图卡 661             │ 右栏 537     │
└──────────────────────┴──────────────┘
```

- 左图卡 `661`，右栏 `537`，间隔 16；
- 右栏纵向堆 2–4 个卡片，卡间隔 12；
- **适用**：一张主图 + 若干条解释；
- **不适用**：四张以上并列图（改 L5）、有先后顺序的步骤（改 L7）。
- 既有页面右栏为 525（历史值），不要求回改。

### L2 宽图 + 窄栏（参考第 8 页）

```
┌──────────────────────────┬────────┐
│  宽图 927                 │ 窄栏 271│
└──────────────────────────┴────────┘
```

- **适用**：趋势曲线、长流程做主视觉，右栏只放 3 个以内的大数字/结论；
- **不适用**：右栏要放表格或长句（改 L1）。

### L3 上下分区

```
┌─────────────────────────────────────┐
│  上区 1214 × ≤250                    │
├───────────┬───────────┬─────────────┤
│ 下卡 394  │ 下卡 394  │ 下卡 394     │
└───────────┴───────────┴─────────────┘
```

- 上区高度 **≤250**（超过则下排挤不下，属设计错误）；
- 下排三卡各 `394`，两张 16px 间距；
- **适用**：图在上、三条结论在下；总—分关系；
- **不适用**：上下内容有强因果、必须并排对照（改 L8）。

### L4 等分三栏

```
┌──────────┬──────────┬──────────┐
│ 394      │ 394      │ 394      │
└──────────┴──────────┴──────────┘
```

- **适用**：三个并列概念，无主次（三个尺度、三种方法、三个判断）；
- **不适用**：有明显主次（改 L1/L2），或四栏（改 L5）。

### L5 等分四栏

```
┌────────┬────────┬────────┬────────┐
│ 291    │ 291    │ 291    │ 291    │
└────────┴────────┴────────┴────────┘
```

- **适用**：四个层级、口径、KPI 数字墙（291×4 + 3×16 = 1212，余 2px 由 `fr` 自动吸收）；
- **不适用**：每栏要放长句（291px 宽约 18 个汉字/行，长句会挤成竖排）。

### L6 全宽表格

- 整幅 `1214 × 434`，表头 + ≤6 行；
- **适用**：对比表、参数表、清单；
- **不适用**：超过 6 行（拆页，或改 L3 上表下结论）。

### L7 横向流程

```
┌──────┬┬──────┬┬──────┬┬──────┬┬──────┐
│ 230  ││ 230  ││ 230  ││ 230  ││ 230  │
└──────┴┴──────┴┴──────┴┴──────┴┴──────┘
```

- 5 步：每步 `230`（4×16 = 64）；6 步：每步 `189`（5×16 = 80）；
- **适用**：步骤、闭环链路、时间轴（有先后顺序）；
- **不适用**：超过 6 步（字会触穿 10px 下限）——拆页，或改 L3。

### L8 双图对比

```
┌──────────────────┬──────────────────┐
│ 599              │ 599              │
└──────────────────┴──────────────────┘
```

- 两栏各 `599`，中间 16；
- **适用**：传统 vs AI、改造前 vs 改造后、两种模型对照；
- **不适用**：两张图量纲不同（并排会误导，改 L1）。

## 2.1 选型：看内容形状，不看哪个好看

| 内容形状 | 选 |
|---|---|
| 1 张主图 + N 条解释 | L1 |
| 1 张大图 + 1 句结论 | L2 |
| 图在上、结论在下（总—分） | L3 |
| 3 个并列概念，无主次 | L4 |
| 4 个并列层级 / 数字墙 | L5 |
| 多行多列数据 | L6 |
| 有先后顺序的步骤（≤6） | L7 |
| 两样东西对照 | L8 |

**判定顺序**：先看有没有先后顺序（→L7），再看是不是成对对照（→L8），再看是不是表格（→L6），最后看「一张图 + 若干解释」（L1/L2/L3）还是「多个并列」（L4/L5）。

## 3. 卡片通用样式

```css
background:#FFFFFF; border:1px solid var(--card-border); /* #D7DCDA */
border-radius:4px; box-shadow:var(--shadow-card);        /* 0 1px 2px rgba(0,60,58,.04) */
padding:10px 16px;                                        /* 左右 16，上下 10 */
```

卡内小节标题（`.pN-kick` 类）：12px / 700 / letter-spacing:1.6px / `--teal-text`。
大数字：26–31px / 700 / tabular-nums / 青绿或橙。
正文：12–12.5px，行高 1.4–1.55，`--text-secondary`。

## 4. 页面类型与节奏

| 页型 | 结构 | 备注 |
|---|---|---|
| 封面 | 大标题居中/左对齐 + 汇报人/日期 | 不放「内部技术汇报」类字样除非用户要求 |
| 主目录 | 3 个章节块 | — |
| 子目录页（每章前插一页） | 参考 slide-3 example | 章号 + 本章小节列表 |
| 内容页 | 布局 A 或 B | 导语条一句话点题 |
| 结尾页 | 致谢/总结 | — |

## 5. 密度要求（国网汇报特点：内容实、不留大空白）

- **框内不得有大块死空间**：卡片高度应贴合内容；若框已定，内容在框内匀开（flex/grid 撑满、`justify-content:space-between/space-around`、末段 `margin-top:auto` 压底）。
- 每页信息承载：≥3 个数据支撑点（KPI/对比/结论），纯文字段不超过 2 行/段。
- 全页墨水覆盖率（QA 指标）0.03–0.65 之间，接近 0.65 会 WARN "very busy"，国网页常偏高属正常。
