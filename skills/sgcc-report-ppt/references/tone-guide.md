# 国网正式汇报口吻规范

> 目标：读起来像「正式汇报材料」而不是「技术博客」或「聊天」。参考真源：整体负荷预测.pptx。

## 句式模板（优先使用）

| 场景 | 句式 | 示例 |
|---|---|---|
| 背景/问题 | 随着……基于……已难以满足要求 | 随着分布式电源大规模接入，基于人工经验的预测模式已难以满足精细化管控要求 |
| 工作/方法 | 针对……开展……，结论为…… | 针对误报偏高问题，开展三轮清单核查，结论为误报以瞬时越线为主 |
| 效果/对比 | 由 X 转向 Y / 较静态提高 X 个百分点 | 由定期重训转向按需更新；较静态提高 10.1 个百分点 |
| 归因 | 表明偏差主要来源于输入侧 | 改用实测温度后误报率下降 18.3 个百分点，表明偏差主要来源于输入侧 |
| 结论收敛 | 综上/由此表明/为进一步……提供支撑 | 由此表明该方案具备规模化推广条件 |

## 禁用（口语化、博客腔）

- 口语词：锅、拉出来、跟着日历走、兜底（正文里）、拉满、卡点、跑通
- 网络腔/第一人称叙述：我们试了下、其实、说白了、大概率
- 感叹、反问句
- 「你」「我」等人称（改用「业务人员」「运维侧」等）

## 数据表述规范

- 百分比差值用「X.X 个百分点」（正文），大数字卡片可缩写 pp
- 精确到给出的精度（如 98.32%），不四舍五入丢失
- 涉及台区/样本量必须带上（如「203 个台区」），不写裸百分比
- 时间口径写全：区间 + 依据（如「模拟区间 2025-07-01 → 2026-03-29（272 天）」）

## 语气校准

- 陈述句为主，动词开头可（「构建…」「实现…」「覆盖…」）
- 每页导语条 = 一句话点题 + 数据支撑，重点 `<b>` 加粗，不超 3 行
- 承上启下用「下一步重点由 X 转向 Y」，不用「接下来我们聊聊」
- 标题用「编号 + 判断句」（如「5.3 更新节奏依据业务实际确定，而非依据日历周期确定」）——这是国网 PPT 常见的「观点式编号标题」
